# Campus Queue
An intuitive, real-time Android application for student queue token generation, live status monitoring, and administration.

## About the App
Campus Queue is designed to streamline academic waiting lines and administrative procedures at university campuses. Students can easily register and request digital tokens for various departments (such as Registrar, Accounts, Admissions, and Student Affairs) directly from their mobile device. The app solves the problem of long, physical waiting lines by providing a live digital queue system, showing real-time serving updates and estimated waiting times. This allows students to manage their time productively instead of waiting in halls, and provides administrators with a secure dashboard to advance, pause, or reset queues efficiently.
